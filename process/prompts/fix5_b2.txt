The create plan page is too much information on one page. Break it into three steps shown as 'Step 1 of 3' etc: 1) experience (run before, optional race times, weekly km), 2) days you can run and long-run day, 3) goal (race distance, start date, race date). Each step has Back and Next, the last one creates the plan. Editing a plan should use the same steps, filled in with its current answers. Don't run tests against the real database in instance/, use a copy. Keep the answers in the Flask session between steps and only save the plan at the last step. Same stack and file layout, no JavaScript.
